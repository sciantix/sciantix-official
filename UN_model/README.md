# UN model workspace

This folder collects the uranium nitride model notebooks, reports, comparison notes,
and calibration artifacts that used to live at the repository root.

## Layout

- `optuna/`: Optuna calibration reports and the self-contained M7 v14 calibration package.
- `comparison/`: model-comparison notebooks and markdown notes.
- `notebooks/`: exploratory UN notebooks.
- `reports/`: thesis/context notes and generated markdown reports.
- `src/`: standalone Python modules for UN model utilities.
- `tests/`: standalone Python tests or scratch checks.

The main current calibration is in `optuna/M7_v14/`.
