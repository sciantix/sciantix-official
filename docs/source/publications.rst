Publications
============

This page lists the main publications on SCIANTIX, with links to the full references. It is not exhaustive: it gathers the papers that describe the code and its models, and the validation and verification work cited in this documentation. Papers on the individual models are cited in the corresponding page of :doc:`models`, and all references are collected in :doc:`references`.
